# Single-Lift-Elevator-System.java
A Java Swing-based Smart Elevator System simulation with animated elevator movement, floor requests, emergency stop, and real-time status updates.

## Features
- Multi-floor elevator simulation
- GUI using Java Swing
- Emergency stop system
- Floor request handling
- Elevator direction logic
- Animated movement

## Technologies Used
- Java
- Swing
- OOPs Concept
